# Musicians Toolkit

A collection of active-recall drilling views for music theory and instrument technique.

## Language

**First Position**:
The canonical beginner left-hand placement on a stringed instrument, where each finger (1–4) sits a diatonic step above the previous one, starting from the open string. For violin: G string → A, B, C, D; D string → E, F♯, G, A; A string → B, C♯, D, E; E string → F♯, G♯, A, B. This app teaches this single canonical pattern only, not the low/high finger variants used for other keys.
_Avoid_: First finger position (ambiguous with "1st finger")

**Fingerboard**:
The flat playing surface under the strings where fingers press to change pitch. Modeled here as 4 strings × 5 positions each (open + fingers 1–4).

**Pitch**:
A specific note at a specific octave (e.g. A4), as opposed to a note *name* (e.g. "A") which is ambiguous across octaves. The violin fingerboard view quizzes by pitch, not name, since a note head drawn on a staff is inherently octave-specific.
_Avoid_: Note (ambiguous between "note name" and "pitch")

**Unison Pairing**:
Two fingerboard positions, on adjacent strings, that produce the same pitch: a string's 4th finger and the next-higher string's open note (e.g. D string 4th finger and open A string are both A4). A classic violin intonation check, and the reason some pitches in first position have more than one correct fingerboard position.
